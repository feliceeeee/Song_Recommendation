# Song Recommendation System Using Content-Based Filtering

A content-based song recommendation system that recommends similar songs based on Spotify audio features and metadata. The project applies exploratory data analysis (EDA), data preprocessing, and cosine similarity to generate song recommendations.

## Highlights

- Exploratory data analysis of song metadata and audio features
- Data cleaning, duplicate removal, and missing value imputation
- Feature engineering using release year
- Audio feature scaling using RobustScaler
- Song similarity calculation using cosine similarity
- Content-based recommendation system based on audio characteristics
- Recommendation results generated from song titles

## Data

The dataset contains **4,999 song records and 19 columns**, including:
- Song and artist information
- Album details and release date
- Song popularity
- Spotify audio features such as danceability, energy, loudness, acousticness, and valence

## Model Experiments

The recommendation system uses a content-based filtering approach with the following techniques:
- Duplicate track removal based on Track URI
- Missing value imputation for categorical and numerical features
- Selection of relevant Spotify audio features
- Feature scaling using RobustScaler
- Cosine similarity to measure similarity between songs
- Recommendation generation based on song titles

## Results

The system generates song recommendations by identifying tracks with similar Spotify audio feature characteristics.
Recommendations can be generated by providing a song title and specifying the number of recommended songs.


5. Run all cells to perform data preprocessing, exploratory data analysis, and song recommendation.
